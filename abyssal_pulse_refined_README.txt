Abyssal Pulse — Refined PC / Mobile Edition

Files
- index.html: device selector; recommends the mobile or PC layout.
- mobile.html: mobile-oriented layout.
- pc.html: PC-oriented layout.

What changed
- The Great Cycle / Memory Coral reward curve is smoother after the first reward. The first Memory Coral still requires 100 million lumens, while later reward milestones arrive sooner than before.
- Korean and English interface copy was polished, and key Great Cycle / purchase messages were clarified across the supported languages.
- Existing facilities, research, expeditions, discoveries, ecological balance, achievements, offline production, and save behavior remain in place. No major new gameplay system was added.
- PC and mobile use the same gameplay logic. Differences are limited to layout and device-friendly presentation/controls.

Compatibility
- The existing browser save key is preserved, so existing local saves remain compatible when you use the same browser and site origin.
- Language choice and progress are stored locally in the browser; they are not automatically synced between different devices or browsers.
- The game defaults to English. Use the language selector in the top bar to change languages.

GitHub Pages
1. Upload index.html, pc.html, mobile.html, and this README to the repository root.
2. Publish the repository with GitHub Pages.
3. Open the root URL; the selector recommends a layout based on the device. Players can still choose either edition.
